# 🖋️ 墨痕 · 人味写作（Mó Hén）— write like a human

> **仓库名与技能包名均为 `mohen`（墨痕 · 人味写作）**。安装时把 `mohen/` 目录放进 Agent 的 Skills 目录即可。

一套「主流程 + 工具库」双层结构的**中文自媒体写作 Skill（v5.4）**：小红书 / 头条 / 百家号 / 公众号，**写前先调研**，套公式成稿，自动过「去AI味硬门槛 + AI味检测 + 质量自评」，让 AI 写的东西留下**人的墨迹**。

> 本 Skill 产出为 **AI 辅助创作**。在各平台发布时请按平台规则勾选「内容含 AI 合成内容」声明（如小红书：发布设置 → 内容类型声明）。

## 特点

- **7 步主流程**：需求确认+写前调研 → 标题产出 → 正文成稿 → 硬门槛自检 → 检测自评 → 平台适配 → 交付+发布+归档。
- **8 个库模块**（SKILL.md + lib/ 共 9 个文件）：
  - 库0 选题与素材 ｜ 库1 标题生成 ｜ 库2 去AI味写作
  - 库3 质控评分 ｜ 库4 平台适配 ｜ 库5 改稿与投稿
  - 库6 写前调研与实战 ｜ 附录 新手速成
- **写前三查**：查平台规则、查同赛道、查自己的历史稿（避开重复选题、借旧稿结构但不抄内容）。
- **陌生平台 5 维度适配框架**：字数 / 段落结构 / 标题风格 / 互动方式 / 合规要求，遇到没收录的平台照框架现拆。
- **多平台通用**：不绑定单一平台；未收录的新平台一律**先查规则再写**，禁止硬套。
- **去AI味体系**：人味内核三要素（观点+细节+情绪）、12 大硬门槛勾选自查、AI 高频词总表、活人感 6 律、4 维 AI 味检测（公式已定死）、50 分自评、一键改稿 Prompt。形式是术，内核是道。
- **配套质检脚本（可选）**：`tools/check_draft.py` 自动扫硬门槛 / AI 词 / 合规词 / 句长段长，本机使用时更快更不漏；无脚本时走人工自查。
- **发布动作卡 + 归档规范**：发布前 / 发布后30分钟 / 次日 三栏清单；定稿后归档并更新索引。

## 使用方法

1. 把 `mohen/`（SKILL.md + lib/ 共 9 个文件）放进支持 Skill 的 Agent 工具（Claude Code / Cursor / Cherry Studio 等）的 Skills 目录。
2. 对 Agent 说「套公式写一篇小红书 / 头条 / 公众号文章」或「去AI味改写这段」。
3. **网页版 AI**：把单文件版 `mohen-v5.4-单文件版.txt` 全文粘贴作为系统指令使用；若对方上下文较小，改用精简版 `mohen-v5.4-精简版.txt`。

## 版本

- **v5.4（当前）**：修掉 12 处「自我一致性」问题（外部评审发现），核心是把**「唯一收口」从词表推广到数字、路径与计算语义**：
  - **示范案例违规修正**：附录示范稿结尾用了"你们"，与"二人称≤1次"冲突 → 新增「**二人称豁免**」（结尾互动句里的"你们/大家"不计入），示范质检描述同步修正
  - **数字口径收口**：小红书字数原先四处打架（500-800／500-600／300-800）→ 统一为 **300-800（教程/合集可到1000）**，库2的2.1 立为「**数字口径唯一收口表**」，别处一律引用
  - **AI味率计算语义定死**：补两句——"每维度扣分下限为 0""单维度累计不超满分"，分子严格落在 0-170，杜绝同一篇稿算出不同百分比
  - **路径降级总协议**（红线 R9）：网页版新增**归档降级**——输出「归档卡」文本让用户复制回本地库，**绝不静默跳过归档**（否则复盘闭环断链）
  - **F 模式补退出条件**：步骤1三要素确认后自动切回 B 流程，不贯穿 7 步
  - **状态锚点增加「文体」字段**（它决定 2.3.1 自检的松紧档位）
  - **翻车教训即时回流**（库6的6.5）：下架原因不等攒够 5 条，当场回写合规表／平台节
  - **头条创作权益**进发布动作卡（漏勾收益少 60%+ 且无法补勾）
  - 其余：红线编号化（R1-R9）、删黑话词典错误注释、原创率改定性表述、精简版加"冲突时以完整版为准"
- v5.3：
  - **反向举证**（库2的2.3.0 ＋ 主流程步骤4）：内核三问**禁止只打 √**，每问必须**引用原文原句**作证据（"细节√ → 原文：'站机床边扫铁屑'"），**举不出原文的一律判 ×**——防 AI 自检放水。
  - **状态锚点**（主流程）：每步输出末尾附 `[步骤N｜平台｜受众｜模式｜字数]`，下一步开头先复述，防长对话指令漂移。
  - **熔断后给「诊断清单」**（库5的5.3）：2 轮改不动时，列出最核心的 3 个结构性问题 ＋ 改不动的原因，给「换方向重写 / 再补素材试一轮」两个选项让用户定夺，不再机械甩"建议重写"。
  - **数字不许裸奔**（红线）：复述权重/收益/推荐量/时间间隔数字时，**必须带**"（截至2026年中经验值，以平台最新公告为准）"后缀。
  - **F 引导模式**：纯新手可说"一步步带我走"，改走「提问→确认→执行」陪跑式，一次只推进一步。
- v5.2：
  - **内核项「一票否决」**（库2的2.3.0 ＋ 主流程步骤4）：形式 12 项全过，若 ①没有明确观点 ②没有只有亲历者说得出的细节 ③没有真实情绪反应 → **直接打回重写**，形式分再高也不放行。
  - **硬门槛分级**：12 项明确为「风格项」（可按文体松紧，给出文体弹性参考）；另立「红线项」（禁AI词 / 禁绝对化 / 禁导流 / 禁编造），**任何文体都不放宽**。
  - **人味内核前置到库2的 2.0**（道先于术）：进库2第一眼是「核心观点＋真实细节＋情绪表达」，而不是一堆替换表。
  - **数据化选题改为「进阶可选」**（库0的0.5）：默认走经验选题法，追求精准时再走数据路径。
- v5.1：
  - 新增「**人味内核三要素**」——核心观点 + 真实细节 + 情绪表达；明确「换词破结构是术，注灵魂才是道」。
  - 新增「**陌生平台 5 维度适配框架**」（库6的6.1）——字数 / 段落 / 标题 / 互动 / 合规，十分钟摸清一个没收录的平台。
  - 新增「**文体制裁**」（库2的2.3）——吐槽文/攻略文/深度长文的段落与语气弹性不同，但红线（禁AI词、禁编造、禁绝对化、禁导流）任何文体都不放宽。
  - 新增「**新手最常栽的 4 个合规坑**」（库2的2.7.1）——图片版权 / 素材来源 / AIGC 合规 / 商业内容报备。
- v5.0：新增库6（写前调研 + 历史稿复用 + 实战数据反哺）；评分公式定死（AI味率 = 四维扣分总和 ÷ 170，50 分自评封顶 50）；AI 词表三处合一；新增归档规范与发布动作卡；受众口径默认「大学生 / 大一新生」；库4 不再被重复读取；配套质检脚本 `check_draft.py`；SKILL.md 精简约 23%。
- v4.2：库模块扩至 7 个、触发词扩展（标题评分 / 标题优化 / 改文案）、改稿「核心问题 2 轮即停」纪律。
- v2.4：头条创作权益 / 首发翻倍 / 垂直权重 / 爆文硬数据门槛；公众号流量主 + 互选广告；小红书 2026 合规红线 / 起号公式。
