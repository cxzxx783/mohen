# zhangwen-craft ｜ 自媒体去AI味写作全流程 Skill

一套「主流程 + 工具库」双层结构的中文自媒体写作 Skill：套公式即可写小红书 / 头条 / 百家号 / 公众号文章，写完自动过「去AI味硬门槛 + AI味检测 + 质量自评」。

> 本 Skill 产出为 **AI 辅助创作**。在各平台发布时请按平台规则勾选「内容含 AI 合成内容」声明（如小红书：发布设置 → 内容类型声明）。

## 特点

- **7 步主流程**：需求确认 → 标题产出 → 正文成稿 → 硬门槛自检 → 检测自评 → 平台适配 → 交付投稿。每一步标注调用的工具库与验收点，不跳步。
- **6 个工具库**：选题素材 / 标题手册 / 去AI味工具箱 / 质检评分 / 平台适配 / 改稿投稿，随用随查，不用通读全手册。
- **去AI味体系**：24 项 AI 痕迹精摘要、12 大硬门槛勾选自查、AI 高频词替换表、活人感 6 律、4 维 AI 味检测、50 分自评、一键改稿 Prompt。
- **平台实操**：小红书 2026 合规红线 + 起号/封面/标签/互动/复盘；头条「创作权益手动开通 + 首发翻倍 + 爆文硬数据门槛」；公众号排版 + 流量主/互选广告变现。

## 使用方法

1. 将本仓库的 `zhangwen-craft` 目录放入支持 Skill 的 Agent 工具（Claude Code / Cursor / Cherry Studio 等）的 Skills 目录中。
2. 对 Agent 说「套公式写一篇小红书/头条/公众号文章」或「去AI味改写这段」，即可触发。
3. 也可以在任意 AI 对话中，把 `SKILL.md` 内容作为系统指令粘贴使用。
