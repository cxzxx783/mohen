# 🖋️ 墨痕 · 人味写作（Mó Hén）— write like a human

> **仓库名与技能包名均为 `mohen`（墨痕 · 人味写作）**。安装时把 `mohen/` 目录放进 Agent 的 Skills 目录即可。

一套「主流程 + 工具库」双层结构的**中文自媒体写作 Skill（v5.0）**：小红书 / 头条 / 百家号 / 公众号，**写前先调研**，套公式成稿，自动过「去AI味硬门槛 + AI味检测 + 质量自评」，让 AI 写的东西留下**人的墨迹**。

> 本 Skill 产出为 **AI 辅助创作**。在各平台发布时请按平台规则勾选「内容含 AI 合成内容」声明（如小红书：发布设置 → 内容类型声明）。

## 特点

- **7 步主流程**：需求确认+写前调研 → 标题产出 → 正文成稿 → 硬门槛自检 → 检测自评 → 平台适配 → 交付+发布+归档。
- **8 个库模块**（SKILL.md + lib/ 共 9 个文件）：
  - 库0 选题与素材 ｜ 库1 标题生成 ｜ 库2 去AI味写作
  - 库3 质控评分 ｜ 库4 平台适配 ｜ 库5 改稿与投稿
  - **库6 写前调研与实战**（v5.0 新增）｜ 附录 新手速成
- **写前三查（v5.0 新增）**：查平台规则、查同赛道、查自己的历史稿（避开重复选题、借旧稿结构但不抄内容）。
- **多平台通用**：不绑定单一平台；未收录的新平台（知乎 / B站 / 抖音图文 / 视频号）一律**先查规则再写**，禁止硬套。
- **去AI味体系**：12 大硬门槛勾选自查、AI 高频词总表、活人感 6 律、4 维 AI 味检测（公式已定死）、50 分自评、一键改稿 Prompt。
- **配套质检脚本（可选）**：`check_draft.py` 自动扫硬门槛 / AI 词 / 合规词 / 句长段长，本机使用时更快更不漏；无脚本时走人工自查。
- **发布动作卡 + 归档规范（v5.0 新增）**：发布前 / 发布后30分钟 / 次日 三栏清单；定稿后归档到稿子库并更新索引。

## 使用方法

1. 把 `mohen/`（SKILL.md + lib/ 共 9 个文件）放进支持 Skill 的 Agent 工具（Claude Code / Cursor / Cherry Studio 等）的 Skills 目录。
2. 对 Agent 说「套公式写一篇小红书 / 头条 / 公众号文章」或「去AI味改写这段」。
3. **网页版 AI**：把单文件版 `mohen-v5.0-单文件版.txt` 全文粘贴作为系统指令使用；若对方上下文较小，改用精简版 `mohen-v5.0-精简版.txt`。
