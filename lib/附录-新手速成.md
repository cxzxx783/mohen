# 附录：新手速成（黑话词典 + 全流程示范案例）
> 给第一次用本技能的人。先扫一眼词典不要被黑话吓到，再照着案例走一遍。

## A. 黑话小词典（大白话解释）
| 术语 | 大白话 |
|---|---|
| 权重 / 账号权重 | 平台觉得你值不值得推，权重高=更容易被更多人看到 |
| 限流 | 平台不给你推荐流量了，发出去只有自己/粉丝看到，像被"捂嘴" |
| 降权 | 权重降低，等同半限流 |
| 冷启动 | 一篇新笔记刚发出、还没有推荐的阶段，靠自评论/转发"点火" |
| 垂类 / 垂直内容 | 只做同一个领域的（比如只做数控/只做数码），不今天发考研明天发美食 |
| 标签 | 带#的话题词，帮助用户搜到你（#大一新生 #开学季） |
| 小眼睛 | 小红书对"笔记被多少人看过"的昵称，小眼睛数=曝光量 |
| 互动率 | (赞+藏+评+转)/浏览，#收藏/评论/转发比点赞更值钱 |
| 完读率 | 看到底的人数占比，高完读=内容好 |
| 点击率 | 看到封面的人里有多少点进来 |
| 涨粉率 | 看的人里有多少关注你 |
| 钩子 | 开头/标题里让人想点开或看下去的那句话 |
| 凤头/猪肚/豹尾 | 开头钩人/中间充实/结尾利落的结构比喻（老话：龙头猪肚凤尾） |
| 洗标签 | 新手期连续刷本领域内容，让平台把你推荐给对的人 |
| 账号收口 | 昵称/简介/主页集中表达"我是谁、帮谁、给什么" |
| 涨粉 / 吸粉 | 给人关注你的理由（"存下来"的有用感） |
| 一稿多发 | 同一篇发多个平台，间隔≥24h避免判搬运 |
| A/B测试 | 出2个标题/封面各发一次对比，看哪个点击高留哪个 |
| 头部 / 大V | 高粉账号；"全大号=存量竞争"意思是蛋糕已被分完，新人难进场 |
| 官方 | 平台方规则（如2026年规则），通常以平台最新公告为准 |

## B. 全流程示范案例（大一新生买电脑避坑·小红书版）
> 演示7步怎么一步步走，新手照这个流程套任意主题。

**步骤1 需求确认** → 确认：小红书 × 主题"大一新生买电脑避坑" × 500-600字 × 用户暂无真实素材（→读库0用公式定题：痛点解式/误区避坑式→选定"误区避坑式"）
> 一句话确认：小红书500字笔记，主题=大一新生买电脑的3个坑，走误区避坑式。

**步骤2 标题产出** → 读库1，套1.4的"人群标签前置+数字清单"：
- 候选1：大一新生｜买电脑前先看这3个坑✨（人群+数字，16字）
- 候选2：别急着下单！大一买电脑最冤的3个花钱法（避雷+数字）
- 候选3：3000块的电脑坑，我帮室友全踩完了😭（亲测+具体）
- 用户选"候选1"→开工（附9维评分简评：人群/搜索/具体性达标，风险=低）

**步骤3 正文成稿** → 读库2，按2.6小红书原生文体，格局=开头3行痛点→3点×120字→结尾行动
> （初稿示范）
> 大一新生｜买电脑前先看这3个坑✨
>
> 开学前一周，我弟兴冲冲要买"游戏本高配"。我把他拽回来说：先听我把三个坑讲完，能省两千。
>
> ① 别信"全能性价比"。又薄又轻还便宜，其实是办公本改的显卡，一打游戏就掉帧。要玩就买正经游戏本，重量别嫌，沉点才是真的。
> ② 别在开学季跟风买"学生机"。同配置官网同价，只是换了个"开学促销"的壳。价差几十块，不如晚两周看口碑。
> ③ 别忽略"售后点"。有的牌子镇上没网点，真坏了快递来回半个月。买之前先查同城有没有授权店，比参数实在。
>
> 说真的，前两年我室友就是栽在第①个上。你们是已经买了还是准备买？评论区吱一声，我看看踩坑名单🥹

**步骤4 硬门槛自检** → 读库2的2.3，逐项√：二人称(0次你)√/路标词√/冒号模板√/讲义动作√/高频句式√/戏剧化√/段落同构√/段落等厚√/段尾收束√/破折号√/粗体√/标点√；再过库4的4.1小红书体检：开头3行有点√/每段≤3行√/emoji密度√/标签4个√/结尾互动√。

**步骤5 检测+自评** → 读库3：AI味<30%(有人味细节"我弟/我室友栽了")、50分自评≈42（直接性40%-扣/真实性满/精炼度略欠）→ 打磨1处删多余修饰→45分通过。

**步骤6 平台适配** → 读库4的4.1：标题16字✓/标签组合=1泛+2精准+1热点(#大一 #新生避坑 #买电脑 #开学季)✓/发布时机=晚21点✓/封面=白底大字"3个坑，别踩"。
- 合规扫描：无极限词(把"最冤"改"挺冤")✓无医疗功效✓无导流✓提醒用户发布时勾"含AI合成内容"。

**步骤7 交付投稿** → 读库5：输出纯文本终稿（无 **加粗**、*斜体*、# 号等Markdown符号），+封面文案"3个坑，别踩"，+建议：晚21点发、当天自评论置顶"还有啥坑？补充~"、转发1个新生群。

> **对照要点**：注意每个步骤都先Read对应库再干活，标题横评给了选择权，自查逐项√/×，结尾给具体行动。这就是完整走一遍的样子。

## C. 头条/百家号短案例（同主题不同写法）
> 同一主题"大一新生买电脑"，头条版和公众号版的差别示范（只看结构，不必全抄）。

**头条版（900-1200字，三行钩子+展开更多切断点+关键词埋点）**：
> 开头三行：没上大学前，我总觉得"电脑随便买买就行"。直到弟弟开学前一周求我帮忙挑，我翻了一晚上参数才发现：大一买电脑，最容易被割的是这3个地方。
> 中段：第一个是"全能本"。看起来又轻又薄，其实显卡是个入门款，玩个游戏就掉帧——这块本来能省不少。第二个是"开学学生机"，换个名字就贵几十块……（展开时在第3-4段结尾留"重点说这个，很多人栽在这"）
> 结尾：说白了就一句：先定用途再谈配置，别听销售把参数往天上吹。你买电脑时踩过啥坑，评论区说说。

**公众号版（1200-2000字，可深可厚，小标题分块，每块3-4段）**：
> 开头150字场景引入（2段）：搬进宿舍的第一个晚上，我室友盯着新买的"高性能本"发呆——他爸给他配了个游戏显卡，结果他要学的是CAD制图。
> 分块1【先想清楚用途再说配置】：展开论证+反例（跟风买游戏本最后都吃灰）……每块配小标题，块间空行留白。
> 结尾150字行动清单：按"专业→预算→售后"三步走的选购顺序列出来，每步一句可落地的动作。

## D. 评分示例（不会打分，照这个标准打）
**9维标题评分示例**：标题《大一新生｜买电脑前先看这3个坑✨》
| 维度(满分) | 得分 | 理由 |
|---|---|---|
| 内容兑现(20) | 18 | 正文确实讲了3个坑，没虚标 |
| 搜索覆盖(15) | 13 | 含"买电脑/大一新生"搜索词 |
| 人群指向(15) | 15 | 大一新生半秒确认"说我" |
| 情绪钩子(12) | 10 | "坑"有悬念，"先看"有紧迫感 |
| 收藏动机(10) | 9 | 避坑清单天然值得存 |
| 具体性(10) | 9 | 有"3个"数字+人群实体 |
| 字数节奏(8) | 7 | 16字，读着顺 |
| 口语感(5) | 5 | 像人话 |
| 独特性(5) | 4 | 同类赛道有区分，非套话 |
| **合计** | **90/100(优秀)** | 强制淘汰无/风险=低 |

**50分自评示例**（对上面正文初稿）：
- 直接性 /10=8（首段有具体事"我弟要买游戏本"，非铺垫）
- 节奏 /10=7（长句后跟了短句；想造不够密，可再拆1句）
- 信任度 /10=8（说了"能省两千"的具体账，没把读者当傻子）
- 真实性 /10=9（有"我室友栽在第①个"真实细节+情绪）
- 精炼度 /10=7（还有1-2处可删的修饰词）
- 加分：真实案例+5，个人情绪+5 → **总分 49/50，优秀**（若AI味检测<30%即绿灯放行）
